# 🌐 WiFi网页控制使用指南

## 🚀 快速开始

### 第一步：上传固件
1. 将 `main_with_wifi.cpp` 重命名为 `main.cpp`
2. 或者直接替换现有的main.cpp文件
3. 编译并上传到XIAO ESP32-C3

### 第二步：连接WiFi
1. 设备启动后，会创建名为 **AmazingHand** 的WiFi热点
2. 在手机或电脑的WiFi设置中连接此热点
3. 密码：**12345678**

### 第三步：打开控制页面
1. 连接WiFi后，浏览器会自动打开控制页面
2. 如果没有自动打开，手动访问：**192.168.4.1**
3. 开始控制你的灵巧手！

## 🎮 控制功能

### 1. 预设动作
- **✊ 握拳** - 所有手指弯曲
- **✋ 张开** - 所有手指伸直
- **✌️ 剪刀** - 食指和中指伸出
- **👍 点赞** - 大拇指向上
- **👉 指向** - 食指指向
- **👌 OK** - 食指和大拇指组成OK手势

### 2. 石头剪刀布游戏
- 点击石头、布或剪刀按钮
- AI会自动做出选择
- 实时显示得分统计
- 支持连续对战

### 3. 精确控制
- **弯曲滑块**：控制手指弯曲程度（20-160）
  - 20 = 完全张开
  - 160 = 完全握拳
- **摆动滑块**：控制手指摆动方向（-100到100）
  - -100 = 最左摆动
  - 0 = 中心位置
  - 100 = 最右摆动

### 故障排除

**无法连接WiFi？**
- 确认热点名称：AmazingHand
- 密码：12345678
- 重启设备等待10秒再连接

**网页打不开？**
- 手动输入：192.168.4.1
- 确认WiFi已连接
- 尝试刷新页面

**动作不响应？**
- 检查舵机连接
- 确认设备电源正常
- 查看串口调试信息
