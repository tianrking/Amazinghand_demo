# 工具集 (Tools)

本目录包含 AmazingHand 机械手的辅助工具脚本，用于快速调试和基础操作。

## 文件说明

### `servo_center.py` - 舵机归中工具
**功能描述**：将所有配置的舵机移动到中间位置（0度）的调试工具。

**主要特性**：
- 支持同时控制多个舵机（16个舵机ID）
- 使用同步写入功能，一次性发送所有舵机指令
- 自动扭矩管理和安全关闭机制
- 循环执行模式，每3秒重复归中动作

**配置方法**：
修改 `SERVOS_CONFIG` 字典来添加或修改需要控制的舵机：
```python
SERVOS_CONFIG = {
    1: 0,   # 食指
    2: 0,
    3: 0,   # 中指
    # ... 添加更多舵机配置
}
```

**使用场景**：
- 机械手初始化设置
- 舵机位置校准
- 系统调试和测试



### `cus_tomiddle.py` - 舵机归中工具（自定义版）
**功能描述**：将所有配置的舵机移动到中间位置（0度）的调试工具，支持自定义舵机配置。

**主要特性**：
- 支持同时控制多个舵机（最多16个舵机ID：1-8, 11-18）
- 使用同步写入功能，一次性发送所有舵机指令
- 自动扭矩管理和安全关闭机制
- 循环执行模式，每3秒重复归中动作
- 基于 rustypot 库的 SCS0009 控制器

**配置方法**：
修改 `SERVOS_CONFIG` 字典来配置需要控制的舵机：
```python
SERVOS_CONFIG = {
    1: 0,   # 食指
    2: 0,
    3: 0,   # 中指
    4: 0,
    5: 0,   # 无名指
    6: 0,
    7: 0,   # 拇指
    8: 0,
    13: 0,
    14: 0,
    11: 0,
    12: 0,
    15: 0,
    16: 0,
    17: 0,
    18: 0,
}
```

**使用方法**：
```bash
python cus_tomiddle.py
```

**使用场景**：
- 机械手初始化设置
- 舵机位置校准
- 系统调试和测试
- 机械手复位到默认状态

### `simple_center.py` - 简易归中工具
**功能描述**：简化版的舵机归中工具，适用于基础测试。

**注意事项**：
- 使用前请确保串口号正确（默认：`/dev/ttyACM0`）
- 按 Ctrl+C 可安全退出程序
- 程序退出时会自动关闭所有舵机扭矩
