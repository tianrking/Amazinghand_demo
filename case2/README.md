# Case 2: SCServo 舵机监控与示教上位机

## 项目简介

这是一个基于飞特(Feetech)SCServo SDK的舵机监控上位机，使用PySide6开发，提供：

- **实时监控** - 监控8个舵机(ID 11-18)的位置、角度、速度、负载状态
- **热插拔检测** - 自动检测舵机连接/断开
- **点位记录** - 记录当前所有舵机位置到JSON文件
- **点位重放** - 读取记录的点位并控制舵机移动
- **扭矩控制** - 失能/启用舵机扭矩，方便手动示教

## 硬件要求

- SCServo舵机（SCS系列）x 8
- 舵机ID配置为 11-18
- USB转TTL串口适配器（支持1Mbps波特率）

## 软件依赖

```bash
# 安装依赖
pip install pyside6 pyserial
```

## 使用方法

### 启动程序

```bash
python servo_monitor.py
```

### 命令行参数

```bash
# 指定串口
python servo_monitor.py --port /dev/ttyACM0

# 列出可用串口
python servo_monitor.py --list-ports
```

### 操作流程

1. **选择串口** - 从下拉框选择正确的串口
2. **开始监控** - 点击"▶ 开始"按钮，程序会扫描ID 11-18的舵机
3. **查看数据** - 表格实时显示各舵机的位置、角度、速度、负载
4. **记录点位** - 调整舵机到目标位置后，点击"📝 记录点位"保存
5. **查看记录** - 点击"📂 查看记录"浏览已保存的点位
6. **应用点位** - 在查看记录对话框中选择点位，点击"应用"让舵机移动

### 扭矩控制

- **🔓 失能** - 禁用舵机扭矩，可手动拖动舵机进行示教
- **🔒 启用** - 启用舵机扭矩，舵机保持当前位置

## 功能特性

### 实时数据显示

| 列名 | 说明 |
|------|------|
| ID | 舵机ID (11-18) |
| 位置值 | 原始位置 (0-4096, 中心2048) |
| 角度 | 换算角度 (位置-2048) × 0.088° |
| 速度 | 当前转速 |
| 负载 | 当前负载 (0-511) |
| 状态 | 运动/静止 |

### 数据变化高亮

当数据发生变化时，对应单元格会闪烁高亮提示。

### 点位数据格式

记录保存在 `servo_positions.json`：

```json
{
  "点位_1": {
    "timestamp": "2025-12-18 16:00:00",
    "servos": {
      "11": { "position": 2048, "angle": 0.0 },
      "12": { "position": 2100, "angle": 4.58 },
      ...
    }
  }
}
```

## 常见问题

### 串口权限问题 (Linux)

```bash
sudo chmod 666 /dev/ttyACM0
# 或添加用户到dialout组
sudo usermod -aG dialout $USER
```

### 未检测到舵机

1. 确认舵机ID在11-18范围内
2. 检查串口连接和供电
3. 确认波特率为1Mbps

### 通信错误频繁

程序已优化通信频率：
- 热插拔检测：2秒间隔
- 数据读取：0.2秒间隔

如仍有问题，检查线路接触是否良好。
