# Case 3: AmazingHand 全自由度动态控制系统

## 项目简介

这是一个基于WebSocket的机械手全自由度控制系统，支持精确的独立控制和动态演示功能。

## 核心特性

1. **全自由度控制** - 独立控制每个手指的弯曲和偏摆角度
2. **动态演示** - 内置多种动态手势动画
3. **实时控制** - WebSocket实时通信，低延迟响应
4. **Web界面** - 简洁直观的HTML控制界面

## 文件说明

| 文件 | 说明 |
|------|------|
| `fulldof_server.py` | WebSocket服务端，处理控制指令和动态演示 |
| `fulldof_control.html` | Web控制界面，支持精确控制 |

## 硬件要求

- AmazingHand 机械手（SCS0009伺服电机 x8）
- 串口控制器（默认端口：`/dev/ttyACM0`）

## 软件依赖

```bash
# Python依赖
pip install websockets numpy
pip install rustypot  # 舵机控制库
```

## 使用流程

### Step 1: 启动服务端

```bash
python fulldof_server.py
```

服务端启动后会：
- 连接串口控制器
- 启动WebSocket服务（ws://localhost:8765）
- 等待Web界面连接

### Step 2: 打开控制界面

用浏览器打开 `fulldof_control.html`

### Step 3: 控制功能

#### 精确控制模式
- **弯曲控制** - 独立调节每个手指的弯曲角度（20°-160°）
- **偏摆控制** - 独立调节每个手指的左右偏摆（-100°到100°）
- **实时预览** - 拖动滑块实时查看角度值

#### 静态手势
- **张开手掌** - 所有手指伸展
- **握拳** - 所有手指弯曲

#### 动态演示
- **指向动画** - 食指伸展并左右摆动
- **胜利手势** - 剪刀手动画
- **抓取动画** - 模拟抓取动作
- **波浪手势** - 手指依次摆动

## 技术特点

### 手指配置
| 手指 | 电机1 ID (弯曲) | 电机2 ID (偏摆) |
|------|----------------|----------------|
| 大拇指 (Thumb) | 11 | 12 |
| 食指 (Index) | 13 | 14 |
| 中指 (Middle) | 15 | 16 |
| 无名指 (Ring) | 17 | 18 |

### 角度范围
- **弯曲角度**: 20° (伸展) - 160° (弯曲)
- **偏摆角度**: -100° (左) - 100° (右)

### WebSocket协议

发送控制指令格式：
```json
{
  "type": "servo",
  "finger": "thumb",
  "bend": 90,
  "yaw": 0
}
```

发送手势指令格式：
```json
{
  "type": "gesture",
  "name": "point_animation"
}
```

## 注意事项

1. 确保串口权限：`sudo chmod 666 /dev/ttyACM0`
2. 建议使用Chrome或Edge浏览器以获得最佳兼容性
3. 程序退出时会自动关闭舵机扭矩确保安全
